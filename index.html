📚 BST Quick Theory

🌱 Insertion

Start from the root. Compare the new value with the current node. Smaller values go left and greater values go right until an empty position is found.

🔍 Searching

Compare the target with each node. If the target is smaller, move to the left subtree. If greater, move to the right subtree.

🗑️ Deletion

  • Leaf node → directly remove.
  • One child → replace with child.
  • Two children → use inorder successor.

🔄 Inorder

Left → Root → Right


In a valid BST, inorder traversal produces values in sorted ascending order.

🌲 Tree Height

Height represents the number of levels in the longest path from the root to a leaf.

⚠️ Skewed BST

If nodes are inserted in sorted order, the BST can become skewed and behave similarly to a linked list.

⏱️ Time Complexity

Deletion O(log n) O(n)
