📚 Binary Search Tree

A Binary Search Tree is a binary tree where smaller values are placed on the left and larger values are placed on the right.

⬅️

Left Subtree

Values smaller than the current node are placed in the left subtree.

🎯

Root Node

The root acts as the starting point of the Binary Search Tree.

➡️

Right Subtree

Values greater than the current node are placed in the right subtree.
